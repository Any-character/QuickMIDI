# QuickMIDI

面向钢琴 MIDI 的**力度分段 + 延音踏板快编工具**：把下载来的钢琴改编 MIDI 按力度层次切段，
逐段快速改力度以适配自己常用的 SFZ 钢琴音色，替代原来在宿主软件里"切段 → 拖到临时轨 → 试听 → 拖回"的低效流程。

## 它与宿主软件的分工

从打谱软件导出的钢琴 MIDI 通常缺少演奏表现：所有音符力度相同、延音踏板按小节
机械地踩放、结尾没有自然衰减。这类问题在 DAW（Cubase、FL Studio 等）中当然可以
修正，但需要先掌握建轨、挂载音源、绘制力度、混音等技能——学习成本远高于问题本身。

QuickMIDI 专注于一件事：把这份 MIDI 调整为接近真实演奏的表现，并导出可分享的音频成品。

| | 宿主软件 | QuickMIDI |
| --- | --- | --- |
| 开始工作 | 建轨、挂载音源、配置路由 | 打开 MIDI 即可试听（钢琴音色内置） |
| 调整力度 | 逐个音符绘制，或使用自动化包络 | 自动分段，调整单条滑杆即可整段变化，段内强弱比例保留 |
| 延音踏板 | 手动绘制 CC64 | 一键按和声重排，切换间隔设有上下限保护 |
| 乐曲结尾 | 需手动预留衰减时间 | 自动保留 5 秒释放尾音，预览与导出一致 |
| 音色润色 | 需学习推子、均衡、总线 | 三个一键功能：自动踏板 / 声像 / 母带处理 |
| 增益安全 | 电平过高会产生削波失真 | 预览固定增益预留余量，导出响度对齐流媒体标准 |

概括而言：**DAW 是通用的音乐制作环境，QuickMIDI 则把"调整钢琴 MIDI 的力度"这一件事
做到无需专业学习即可使用。**

## 快速开始

```bat
pip install -r requirements.txt
run.bat
```

双击 `run.bat` 等价于 `python -m qmidi`；也可以把 `.mid` 文件直接拖到 `run.bat` 上。
也可以安装为命令使用：`pip install .` 之后直接运行 `qmidi`。

1. 打开一个 `.mid`（钢琴曲最合适）；
2. 在轨道列表选一条轨，卷帘只显示这条轨的音符（设置里可开全显示）；
3. 选中一个力度段，拖力度条或按 `↑↓` 微调；
4. 满意后「导出」→ MIDI 或 MP3。

## 功能一览

- **自动切段**：按力度层次与重复乐句自动分段，段是编辑的基本单位；
  规则升级后可用工具栏「重切」按新规则重切（会丢段调整，可撤销）。
- **整段比例缩放**：拖动任意一根力度条，以所抓取的音符为基准对整段等比缩放
  （例如段内力度为 100 与 90，将 100 调整至 50 时，90 会等比变为 45，而非线性地变为 40）。
- **自动踏板**：按和声变化重排延音踏板，两次切换之间设有最小/最大间隔限制；
  踏板按通道生效，同一通道的多条轨道共享同一份踏板。
- **声像**：双钢琴作品可一键将两架钢琴分别置于左右声道；只写入导出文件，不影响预览。
- **母带**：混响 + 温和压缩 + 限幅 + 响度标准化（-14 LUFS），只作用于 MP3，默认关闭。
- **BPM 可调**：整体缩放 tempo 表（文件里的渐慢等记号保留）。
- **所见即所听**：预览与导出共用音源、踏板、尾音规则；导出有真实进度条。
- **自定义**：快捷键、界面语言（中文/English）、只显示当前轨、播放头吸附、导出质量。

## 你的数据在哪

- **原始 `.mid` 文件不会被修改。** 力度段、踏板、轨道名、BPM、声像、母带开关
  都保存在曲子旁的 `<曲名>.mid.qmidi.json`（sidecar）文件中；
- 删除 sidecar 即可恢复原始状态；文件损坏时自动回落到默认值；
- 界面语言、音源等全局设置在 `%APPDATA%\QuickMIDI\settings.json`，快捷键在同目录 `keymap.json`。

## 技术栈

| 用途 | 选型 |
| --- | --- |
| 语言 / 脚本 | Python 3.10+ |
| GUI | PySide6-Essentials（LGPL 路线，不用 PyQt6） |
| MIDI 读写 | mido |
| SFZ 采样音源 | sfizz（经 pysfizz 绑定，直接内嵌，不借助 loopMIDI） |
| 音频 / 编码 | soundfile、lameenc（MP3 多码率导出） |

## 模块

| 模块 | 职责 |
| --- | --- |
| `src/qmidi/engine.py` | pysfizz 适配层（只暴露 6 个动作，其余代码不 import pysfizz） |
| `src/qmidi/offline.py` | 时间线、任意位置 seek 的状态重建、分块渲染、进度回调 |
| `src/qmidi/segments.py` | 力度段模型（含比例缩放）、自动切段、sidecar 读写 |
| `src/qmidi/pedal.py` / `pedal_auto.py` | 踏板段模型；按和声自动生成踏板 |
| `src/qmidi/mastering.py` | MP3 母带链（混响/压缩/限幅/响度） |
| `src/qmidi/exporters.py` | MIDI 外科式导出、MP3 导出（声像、母带、进度） |
| `src/qmidi/keymap.py` / `i18n.py` / `settings.py` | 快捷键、界面语言、用户设置（三者皆无 Qt） |
| `src/qmidi/gui/` | 主窗口、钢琴卷帘、轨道/段/踏板面板、设置窗口 |

## 开发

- 测试：`python -m pytest -q --basetemp=tmp/pytest`。
  其中依赖 `example/` 目录真实 MIDI 的测试（版权原因不入库）会在文件缺失时自动跳过；
- 界面文案全部走 `src/qmidi/i18n.py` 的 `tr()`（中文为源语言，英文表在同文件）；
- 架构约定：核心逻辑（`src/qmidi/`，含渲染、切段、踏板、导出）不依赖 Qt，
  Qt 只出现在 `src/qmidi/gui/`；音源路径一律来自 `SFZ_PATH` 环境变量或设置文件，
  不硬编码。
